# ubuntuRicePack WSL packages
# Targets: Ubuntu 25.04 (Plucky) and Ubuntu 26.04 LTS (Resolute) under WSL 2
# Translated from the Arch WSL pacman inventory on 2026-07-24.
#
# This is a release-spanning superset. The installer checks the active APT
# index and installs only packages available for the detected release. It
# ignores blank lines and lines beginning with '#'.
#
# Required Ubuntu components: main, universe, multiverse.
# Policy: CLI-focused, no Snap packages.
#
# Important command-name differences to handle later in the terminal script:
#   Arch `bat` -> Ubuntu package `bat`, command `/usr/bin/batcat`
#   Arch `fd`  -> Ubuntu package `fd-find`, command `/usr/bin/fdfind`
# `tealdeer` supplies the `tldr` command.
