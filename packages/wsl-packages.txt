# ==========================================================
# wsl-packages.txt (Ubuntu/apt version)
# CLI-only subset, Ubuntu/apt equivalents of the Arch/pacman list.
# Same category exclusions as the Arch version apply here —
# no desktop shell, no GUI apps, no bare-metal/hardware
# daemons, no host networking/audio stack inside WSL.
#
# Notes on packages that don't map 1:1:
#   - `bat`      -> binary is `batcat` on Ubuntu.
#                   ln -s /usr/bin/batcat ~/.local/bin/bat
#   - `fd`       -> package is `fd-find`, binary is `fdfind`.
#                   ln -s $(which fdfind) ~/.local/bin/fd
#   - `eza`      -> not in default Ubuntu repos pre-24.04; add the eza
#                   apt repo (see github.com/eza-community/eza).
#   - `starship` -> not in apt; curl -sS https://starship.rs/install.sh | sh
#   - `fastfetch`-> only in Ubuntu 23.10+ universe; else add its PPA.
#   - `pyenv`    -> not in apt; curl https://pyenv.run | bash
#   - `7zip`     -> `p7zip-full` covers this on older Ubuntu releases.
#   - `tk`       -> `tk-dev` (dev headers, needed for pyenv Python builds).
#   - `sqlite`   -> `libsqlite3-dev` (dev headers, for pyenv builds).
#   - `openssl`/`zlib`/`xz`/`bzip2`/`libffi`/`readline`/`ncurses` are all
#     needed as *-dev packages for building Python via pyenv, not the
#     runtime libraries (which Ubuntu already ships).
# ==========================================================
