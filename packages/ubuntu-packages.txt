# Core packages required by the rice installer.
# Ubuntu/Debian (apt) equivalents of the Arch/pacman list.
#
# Notes on packages that don't map 1:1:
#   - `bat`      -> binary is `batcat` on Ubuntu (name collision with another package).
#                   Symlink: mkdir -p ~/.local/bin && ln -s /usr/bin/batcat ~/.local/bin/bat
#   - `fd`       -> package is `fd-find`, binary is `fdfind`.
#                   Symlink: ln -s $(which fdfind) ~/.local/bin/fd
#   - `eza`      -> not in default Ubuntu repos pre-24.04; add the eza PPA/repo:
#                   https://github.com/eza-community/eza/blob/main/INSTALL.md#debian--ubuntu
#   - `starship` -> not in apt; install via: curl -sS https://starship.rs/install.sh | sh
#   - `fastfetch`-> only in Ubuntu 23.10+ universe; otherwise add the fastfetch PPA.
#   - `pyenv`    -> not in apt; install via: curl https://pyenv.run | bash
#   - `keyd`     -> not in apt; build from source or use a .deb from upstream releases.
#   - `ventoy-bin` -> not in apt; download the official .tar.gz from ventoy.net.
#   - `google-chrome` -> add Google's apt repo, not in default Ubuntu repos.
#   - `visual-studio-code-bin` -> add Microsoft's apt repo.
#   - `7zip`     -> `p7zip-full` covers most needs; the newer standalone `7zip`
#                   package exists on Ubuntu 23.10+, else use p7zip-full.
#   - `nerd-font` ttf packages -> Ubuntu doesn't package Nerd Fonts; download
#                   manually from https://www.nerdfonts.com/font-downloads
